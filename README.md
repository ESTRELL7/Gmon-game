# Deep Dwarf

Пиксельная игра про дворфа-шахтёра. Копай вниз, собирай руду, продавай её в лавке и улучшай снаряжение. Чем глубже шахта, тем ценнее руда и твёрже порода.

Unity 6000.3.23f1. Платформы: Android и WebGL.

## Как играть

- Стрелки на экране, стрелки клавиатуры или WASD: идти и копать в эту сторону.
- Копание вниз и вверх оставляет лестницу, по ней можно вернуться.
- Подъём вверх по лестнице и каждый удар киркой тратят силы.
- Кнопка «Подъём» (или пробел) мгновенно возвращает на поверхность. Чем глубже, тем больше сил она стоит.
- Если силы кончатся под землёй, дворфа вытащат наверх, но половина руды потеряется.
- На поверхности руда продаётся сама, а в лавке покупаются улучшения: кирка, замах, рюкзак, выносливость, фонарь, подъёмник и удача.

## Слои и руды

9 слоёв от почвы до бездны, 11 руд от угля до адамантита. Все числа баланса лежат в `Assets/Resources/GameConfig.asset`, их можно менять в инспекторе.

## Структура

| Папка | Что внутри |
|---|---|
| `Assets/Scripts/Core` | Правила игры без графики: мир, копание, экономика, сохранения |
| `Assets/Scripts/View` | Отрисовка мира, дворфа, интерфейса, звуки |
| `Assets/Editor` | Импорт пиксель-арта, настройка проекта, сборки |
| `Assets/Tests/Editor` | Автотесты и бот, проверяющий баланс |
| `Assets/Resources/Art` | Спрайты (можно перерисовать, сохранив имена и размеры) |
| `Art/Source/dwarf.aseprite` | Исходник дворфа |
| `Tools/generate_art.py` | Генератор временной графики, звуков и шрифта |

## Графика

Дворф нарисован в Aseprite (`Art/Source/dwarf.aseprite`), кадры ходьбы и дыхания строятся из него. Остальное временно сгенерировано скриптом:

```
python Tools/generate_art.py
```

Скрипт перезаписывает файлы в `Assets/Resources/Art`. Перерисованные вручную спрайты не перезапускайте через него.

## Сборка

Меню **Tools → Deep Dwarf**: Setup Project, Build WebGL, Build Android APK, Reset Save.
